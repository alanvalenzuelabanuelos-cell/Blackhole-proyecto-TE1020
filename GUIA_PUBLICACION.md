# Guía de publicación — Blackhole01 (GitHub Pages)

1. Descomprime el archivo `Blackhole01_Auditoria_Final.zip`.
2. Accede a tu repositorio de GitHub o crea uno para el proyecto TE1020.
3. Sube **el contenido interior de la carpeta `blackhole01/`** (no la carpeta contenedora si deseas alojar el sitio en la raíz): `index.html`, `app.js`, `solar.js`, `maps.js`, `styles.css`, `solar.css`, `landing.html`, directorios `assets/` y `docs/`, y los archivos informativos.
4. En el repositorio abre **Settings → Pages → Build and deployment** y elige **Deploy from a branch → main → /(root)**; guarda los cambios.
5. Abre la URL que GitHub Pages indique cuando se publique. Comprueba rutas, pestañas de Transmisión, `3 · Distribución`, `4 · ¿Sabías que?`, y el Cotizador completo.
6. Para verificar el Cotizador sin inventar precios, registra primero cargas y calcula con HSP, PR y Wp. Para obtener presupuesto y PDF aporta las fichas y precios comerciales que hayas documentado.
7. El mapa de distribución funciona sin Internet porque es una figura local; los mapas oficiales de CENACE y SEMARNAT se consultan fuera del repositorio y requieren Internet. Si un servidor impide la visualización embebida, utiliza el enlace **Abrir mapa completo** proporcionado junto a la figura.
8. Si estás reemplazando una publicación anterior, actualiza la pestaña con **Ctrl + F5** (Windows) para forzar el uso de archivos nuevos.

## Precauciones

- El proyecto es académico; no certifica equipos ni instalaciones.
- No se precargaron componentes ficticios ni precios. Los ejemplos de prueba no forman parte de la entrega.
- Los datos históricos de CFE 2022–2024 y PRODESEN 2023–2037 tienen fecha y alcance especificados.
- Los mapas institucionales externos pueden cambiar o dejar de responder. Ver `AUDITORIA_FINAL.md`.
- Esta guía **no afirma** que ya se haya publicado la web. La publicación la realiza la persona con permisos del repositorio.
