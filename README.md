# BLACKHOLE01 | Atlas Eléctrico + Cotizador Fotovoltaico

Versión posterior a la auditoría final TE1020 · 06/11/2026.

## Abrir

Abre `index.html` en Chrome o publica estos archivos estáticos en GitHub Pages. El sitio no requiere compilación. Las fuentes institucionales de mapas remotos sí requieren conectividad y pueden bloquear el embebido. `landing.html` conserva la Landing Page original.

## Lo incluido

- Módulo 0: Recursos energéticos; 15 clasificaciones, transformaciones, comparador y reflexión.
- Módulo 1: Generación; indicadores CFE 2022–2024, gráfico tecnológico, 16 fichas por estado y mapa remoto institucional (histórico).
- Módulo 2: Transmisión; datos CFE, mapa de regiones CENACE (documento remoto) y simulador trifásico.
- Módulo 3: Distribución; CFE 2022–2024, mapa estático original de 16 divisiones CFE 2023 y transformador ideal.
- Módulo 4: ¿Sabías que?; 20 hallazgos, gráficos y cronología 2013–2025.
- Cotizador Fotovoltaico: cálculo PRELIMINAR disponible sin catálogo; cotización y PDF cuando se aportan componentes y precios verificados.

## Archivos

- `index.html`: aplicación y navegación.
- `app.js`, `solar.js`, `maps.js`: lógica de actividades, cotizador y mapa remoto.
- `styles.css`, `solar.css`: estilos híbridos científicos.
- `assets/cfe-divisiones-2023.png`: imagen del mapa CFE del Informe Anual 2023, página impresa 132.
- `docs/`: fuentes PDF aportadas PRODESEN capítulo 4 e Informe CFE 2022.
- `AUDITORIA_FINAL.md`: errores encontrados, correcciones y limitaciones.
- `GUIA_PUBLICACION.md`: pasos para GitHub Pages.

No se incluyen los productos ni los precios inventados durante la auditoría. Los valores no documentados deben ingresarse y verificarse, no fabricarse.
